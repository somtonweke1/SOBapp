# Client Call Script (Non-Coercive)

## 1) Intro (30 seconds)
"Hi, this is Somto from StoneBridge. We help Baltimore property owners recover avoidable utility overcharges and keep compliance records audit-ready. I reviewed your property profile and noticed indicators worth validating. Would you be open to a quick walkthrough?"

## 2) Context and Credibility
"This is not software onboarding. We run a forensic review, quantify impact, and handle execution. Most owners use us because they do not have time for filing workflows."

## 3) Discovery Questions
1. "How is utility billing currently reviewed and approved?"
2. "Have you had a meter class or account audit in the last 3 years?"
3. "Who currently owns filings and compliance deadlines internally?"
4. "Would you prefer contingency for recoveries or fixed-fee handling?"

## 4) Value Framing
"If we find a validated discrepancy, we handle packet preparation and filing support end-to-end. If there is no recoverable outcome, there is no contingency fee."

## 5) Close to Next Step
"Next step is simple: we execute an authorization and intake checklist, then deliver a findings packet with estimated value and recommended action path. Can we schedule that for this week?"

## 6) Objection Handling
- "We already have a consultant."
"Understood. We can run a narrow diagnostic and coordinate with your current advisor."

- "Send info first."
"I will send a one-page scope and sample deliverable. If it fits, we do a 20-minute scoping call."

- "No budget."
"For recovery work, the default model is no recovery/no fee. We can defer retainer discussions until value is realized."

## 7) Email Follow-Up Template
Subject: Next Step - Property Audit Scope

Body:
"Thanks for your time today. As discussed, StoneBridge will run an initial forensic review for [PROPERTY].  
Deliverables: findings summary, estimated value band, and execution path.  
Commercial model: contingency for recoveries, optional monthly compliance support.  
Please reply with the authorization contact and last 12 months of utility statements."
