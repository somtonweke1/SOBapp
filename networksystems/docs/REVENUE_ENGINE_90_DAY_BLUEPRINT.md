# Revenue Engine 90-Day Blueprint

## Objective
Build a services-led revenue engine using the platform as an internal operating system.

Targets for first 90 days:
- Monthly Recurring Revenue (MRR): `$5,000+`
- One-time project revenue: `$15,000+`
- Contingency pipeline: `$100,000` in estimated recoverable value

## Offer Ladder
1. Utility Recovery Audit (contingency)
- Promise: recover overcharges or pay nothing.
- Fee: `25% to 35%` of realized refund/credit.
- Average deal: `$5,000 to $15,000` fee.

2. Compliance Shield (retainer)
- Promise: continuous monitoring, filing cadence, vendor coordination.
- Fee tiers: `$500`, `$1,200`, `$2,500+` per site/month.

3. Risk Remediation Advisory (project)
- Promise: preemptive correction of classification, permit, and record inconsistencies.
- Fee bands: `$7,500`, `$15,000`, `$30,000`.

## Legitimate Leverage Strategy
Use operational depth, not pressure:
- Become system of record for findings, filings, and evidence history.
- Own execution calendar for deadlines, submissions, and follow-ups.
- Publish monthly scorecard: money recovered, risks resolved, deadlines met.
- Create switching costs with standardized dossier and audit trail formats.

## Weekly Operating Cadence
Monday:
- Add `15 to 25` new targets.
- Run triage scans.
- Rank by expected value and urgency.

Tuesday:
- Build evidence packets for top `10`.
- Prepare outreach list and owner contacts.

Wednesday:
- Send `10` packets.
- Run call blocks.

Thursday:
- Discovery + closing calls.
- Issue proposals and SOWs.

Friday:
- File active client submissions.
- Update dashboard KPIs.
- Hold pipeline review.

## Core Funnel Metrics
- New targets/week: `>= 20`
- Outreach packets/week: `>= 10`
- Calls booked/week: `>= 5`
- Proposals sent/week: `>= 3`
- Closed-won/month: `>= 3`
- Contingency-to-retainer conversion: `>= 35%`
- Blended gross margin: `>= 65%`

## 90-Day Milestones
Days 1 to 14:
- Finalize offers, scripts, and contract templates.
- Build first `50` Baltimore targets.

Days 15 to 45:
- Execute outreach cadence.
- Close first contingency deals.
- Deliver first client wins quickly.

Days 46 to 75:
- Convert active clients to monthly retainer.
- Add referral partners (attorney, CPA, waste vendor).

Days 76 to 90:
- Standardize delivery SOPs.
- Raise pricing for new deals based on proof and capacity.

## Delivery Stack (Internal)
- Evidence Packet (PDF)
- Proposal + SOW
- Filing Checklist
- Monthly Assurance Report
- Renewal + Upsell Review
